# Cat Maze Games

Pac-Man style browser games starring two orange cats.

- `rhys/`: **Rhys in PDX**. Rhys eats Churu treats around downtown Portland, dodges rain clouds, and drives a RAV4 after a Baby Doll Pizza slice.
- `magnus/`: **Magnus in PB**. Magnus eats shrimp across Pacific Beach, San Diego, dodges vacuum cleaners, and eats a burrito to fight back.

Each game is a single HTML file with no build step. Open it in any browser, or serve this folder with GitHub Pages.

Play online: https://jakekaucher-sudo.github.io/maze-games/
